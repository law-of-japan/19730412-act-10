## 手順

1. 1・2画像は祝日法リポジトリに保存した画像を複写し、ハッシュを確かめる。3〜5画像を取得し、URL・取得日・SHA-256を `docs/sources/downloads.json` に記録する。
2. revision_idをCrockford Base32小文字8字でランダム発行し、衝突を確かめる。
3. 本則は項の形式の本則（PARA-03）、改正の指示と加える項・ただし書は改正規定（AMEND-01〜03）で書く。附則は項ごとに見出しを付ける。字体は正規化せず、決められない字は `glyphs.yaml` に注記する。
4. `history.yaml`（制定の版、公布の日から施行）と `rebuild.yaml`（旧commitの対応、旧本文との差）を作る。
5. L0・L1、L3（historyStructure・evidence）、rebuild、registry、L4を実行し、結果を `docs/validation/` に保存する。
6. 前例と同じく `revisionAdd`（版と履歴）と `metadata`（再構築報告）、`auxiliary`（記録・README・CI）にcommitを分ける。

## 完了条件

版・再構築報告が検査器で検査でき、原典の閲覧範囲と官報未照合の限界が記録されていること。
